Focus privacy policy

Extension versions: 0.1.0–0.2.0. Last updated: October 22, 2026.

Focus processes pages only on websites the user adds and grants access to in Chrome. It reads page structure to apply blur to selected visual elements. Images and videos are not uploaded or analyzed by external services.

Only configured domains, category switches, blur strength, image mode, minimum image size, enabled state, and pause deadlines are stored in chrome.storage.local. Settings are not synced between devices. Website content scripts cannot directly access this settings store through the extension storage API.

There are no accounts, backend services, analytics, advertising SDKs, remote code, extension network requests, or telemetry. Focus does not store browsing history, individual page URLs, page text, images, videos, or form contents. The websites themselves continue to load their own resources normally.

Permissions

  • storage: save preferences on this device.
  • scripting: inject bundled CSS and local scripts into permitted websites.
  • alarms: end a one-hour pause automatically, including after a browser restart.
  • activeTab: identify the current website when the toolbar button is clicked.
  • Optional HTTP/HTTPS host access: requested separately when the user adds a website. Declaring all possible HTTP/HTTPS addresses in optional_host_permissions allows the user to choose any domain; it does not grant access to all websites on installation.

Users can remove configured sites and revoke access in Chrome. Uninstalling the extension removes its local settings. Chrome and the operating system may independently back up browser profiles according to the user's preferences.

Policy website

This policy describes the Focus extension. Its public policy page is hosted using GitHub Pages. Visits to that page are handled by GitHub under the GitHub Privacy Statement. The policy page itself contains no analytics, remote fonts, or tracking scripts.
